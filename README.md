# Emran's Electric Portfolio

Build a polished, original, highly interactive personal developer portfolio for Emran, titled “Frontend Developer | JavaScript Developer,” using the attached image only as inspiration for its premium dark navy/black, electric-blue-glow, clean futuristic visual language. Implement the full specified one-page responsive experience: sticky active-link navbar with dark/light mode persisted locally and animated mobile menu; hero with stated copy and original abstract developer visual; about with editable modest placeholder stats; animated entrance glass service cards; skill icons in an infinite left-to-right marquee that pauses on hover and never overflows; featured project cards with editable GitHub and Live Preview links; editable placeholder testimonials (no real/famous identity claims); frontend-only validated contact form explicitly indicating it needs a form service/backend; footer. Use Space Grotesk only for headings and Inter only for body. Ensure semantic accessible markup, keyboard/focus states, reduced motion support, no broken buttons/links or fake sending behavior, and responsive behavior from 320px upward. Use React, Tailwind, Lucide/React Icons and Framer Motion only as needed, with clean reusable components and data. Enable a backend only if it is genuinely necessary; this brief does not need one.
